# 变更提案: Emby TV 客户端功能补齐

## 需求背景
当前客户端已经完成 Emby 登录、首页真实数据、媒体库列表、收藏页、详情页、播放页和播放状态上报。与一个可日常使用的 TV 客户端相比，仍缺少搜索、播放中音轨/字幕切换、剧集连续播放、用户态写操作、多服务器/多用户管理，以及合集、播放列表、类型、演员等发现入口。

用户明确要求高优先级缺口中除转码策略外都需要实现，并要求中优先级实现合集 / 播放列表 / 类型 / 演员页。本方案包覆盖这些能力的实现规划。

## 产品分析

### 目标用户与场景
- **用户群体:** 使用 Android TV 遥控器访问 Emby 媒体库的家庭用户。
- **使用场景:** 通过电视查找影片、切换字幕音轨、连续看剧、管理收藏/已播放状态，在合集、播放列表、类型和演员维度浏览资源。
- **核心痛点:** 当前只能沿首页和媒体库路径浏览，播放器内轨道入口是禁用态，剧集播放缺少上一集/下一集/连播，收藏页只读，多个服务器或用户身份无法切换。

### 价值主张与成功指标
- **价值主张:** 让客户端从“能播放”升级到“可长期作为主力 TV Emby 客户端使用”。
- **成功指标:** 搜索和发现页均展示真实 Emby 数据；播放页可用遥控器切换音轨/字幕和连续播放；收藏/已播放写操作能同步回 Emby；重启后可选择已保存服务器和用户。

### 人文关怀
TV 端输入成本高，搜索必须支持遥控器可控的软键盘路径，并在设备支持时提供语音输入；用户态写操作必须给出可撤销或明确反馈，避免误标记已播放、误取消收藏。

## 变更内容
1. 新增搜索与语音搜索入口，搜索电影、电视剧、剧集、合集和播放列表。
2. 播放器实现真实音轨/字幕选择、上一集/下一集和剧集自动连播。
3. 新增收藏/取消收藏、标记已播放/未播放、清除继续观看进度等 Emby 用户态写操作。
4. 将单凭证存储升级为多服务器/多用户凭证列表，并提供 TV 可操作的账户选择/删除入口。
5. 新增合集、播放列表、类型、演员四类发现页面，并复用详情页和播放页链路。

## 范围边界
- **范围内:** 搜索/语音搜索；音轨/字幕切换；剧集播放队列；收藏与播放状态写操作；多服务器/多用户选择；合集、播放列表、类型、演员页的展示、进入详情和播放。
- **范围外:** 转码策略、播放兼容性探测、Live TV/DVR、音乐专辑/歌曲完整体验、播放列表创建/编辑、合集创建/编辑、服务端管理功能。
- **拆分说明:** 本需求涉及多个可交付能力，但它们都围绕“TV 客户端主功能补齐”同一目标；方案按共享 API/模型、搜索发现、播放器、用户态操作、多凭证五个实施切片组织，后续执行时可按任务分批提交。

## 核心场景

### 需求: 搜索与语音搜索
**模块:** ui/home, data
用户在顶部栏或抽屉打开搜索页后，可以输入关键词或触发系统语音识别；搜索结果按电影、电视剧、剧集、合集、播放列表展示真实 Emby 数据。

#### 场景: 遥控器搜索
已登录状态下：
- 搜索页首个输入框获得焦点，方向键可在输入框、语音按钮、清空按钮和结果卡片之间移动。
- 输入关键词后调用 Emby 搜索接口并显示封面、名字、类型、进度/剩余集数。
- Movie/Series/BoxSet 进入详情或列表页，Episode 可直接播放，Playlist 进入播放列表详情。

#### 场景: 语音搜索
设备支持语音识别时：
- 语音按钮启动 Android 语音输入，返回文本后自动触发搜索。
- 不支持或取消时回到手动输入，并显示可读提示。

### 需求: 播放器音轨/字幕与连续播放
**模块:** ui/player, data
播放器 OSD 中 Audio/Subtitles 不再是禁用态，上一集/下一集按钮可用于剧集队列。

#### 场景: 轨道切换
播放页 OSD 显示后：
- Audio 打开音轨列表，Subtitles 打开字幕列表和“关闭字幕”选项。
- OK/Enter 选择轨道后，Media3 立即切换当前播放轨道，OSD 状态同步为选中项。
- 无可用轨道时显示明确禁用原因。

#### 场景: 连续播放
播放剧集时：
- 播放源携带上一集/下一集队列信息。
- OSD 上一集/下一集按钮可聚焦并切换播放。
- 当前集自然播放结束时自动播放下一集；没有下一集时停止并返回可读提示。

### 需求: 收藏与播放状态写操作
**模块:** ui/home, data
用户可在详情页和媒体卡片操作收藏、已播放和继续观看状态，所有写操作同步 Emby。

#### 场景: 收藏切换
Movie/Series/Episode 可操作区域：
- 展示当前 `UserData.IsFavorite` 状态。
- OK/Enter 触发收藏或取消收藏，成功后刷新当前卡片/详情状态。
- 失败时保留原状态并提示，不输出 token 或完整 URL。

#### 场景: 播放状态切换
详情页或更多操作菜单：
- 可标记已播放或未播放。
- 可清除继续观看进度；如 Emby 接口行为与预期不一致，保留失败提示，不强制本地伪造状态。

### 需求: 多服务器/多用户
**模块:** ui/setup, data/local
客户端支持保存多个 Emby 服务器和用户身份，方便家庭成员或多服务器切换。

#### 场景: 启动选择身份
存在多个已保存凭证时：
- 启动后显示账号选择页，卡片展示服务器地址、用户名、保存时间。
- OK/Enter 选择后使用 token 恢复会话。
- 可删除某个凭证；删除前必须二次确认。

### 需求: 发现页
**模块:** ui/home, data
抽屉新增合集、播放列表、类型、演员入口，均展示真实 Emby 数据。

#### 场景: 合集页
用户进入合集：
- 显示 BoxSet 卡片、封面、名称、资源数量。
- OK/Enter 进入合集详情，展示合集内 Movie/Series。

#### 场景: 播放列表页
用户进入播放列表：
- 显示 Playlist 卡片。
- OK/Enter 进入列表详情，展示列表条目；Episode/Movie 可播放，Series 进入详情。

#### 场景: 类型页
用户进入类型：
- 显示 Genre 卡片和封面。
- OK/Enter 进入该类型下的 Movie/Series 资源列表。

#### 场景: 演员页
用户进入演员：
- 显示 Person 卡片和头像。
- OK/Enter 进入人物详情，展示该演员关联的 Movie/Series。

## 风险评估
- **风险:** 收藏、已播放、清除继续观看是写操作，误触会改变 Emby 用户数据。
- **缓解:** 所有写操作只在用户明确按 OK 后执行；删除凭证和清除进度提供二次确认；失败回滚 UI 乐观状态。
- **风险:** Emby 不同版本对 BoxSet、Playlist、GenreIds、PersonIds 和搜索总数字段支持存在差异。
- **缓解:** 以官方接口为主，结合测试服只读探测；实现时所有 DTO 字段可空，列表以 `Items` 为准，`TotalRecordCount` 仅作参考。
- **风险:** 播放器轨道切换需要匹配 Media3 当前 tracks，不能只依赖 Emby stream index。
- **缓解:** 使用 Media3 当前 `Tracks` 作为实际可选轨道来源，Emby `PlaybackInfo` 只作标题和兜底元数据。
