# 变更提案: 首页媒体库与最新资源展示增强

## 需求背景
当前登录后的首页只展示媒体库卡片和一条“继续观看/最近入库”横排，信息层级不足。用户期望媒体库区域明确展示真实媒体库名称和封面图；继续观看需要展示媒体缩略图和剧集信息；继续观看下方还需要按各个媒体库展示最新的几条媒体资源，便于进入后立即浏览不同库的新增内容。

## 产品分析

### 目标用户与场景
- **用户群体:** 使用 Android TV 浏览 Emby 媒体库的家庭用户。
- **使用场景:** 登录后在客厅电视首页快速判断有哪些媒体库、哪些内容可继续播放、各媒体库最近新增了什么。
- **核心痛点:** 单一横排无法表达“按库组织”的 Emby 内容结构；Episode 只显示标题会丢失剧名、季集号等上下文。

### 价值主张与成功指标
- **价值主张:** 首页成为真实 Emby 媒体中心，而不是单一列表入口；用户无需进入二级页即可看到各库最新内容。
- **成功指标:** 首页媒体库卡片使用 Emby `Views` 名称和封面；继续观看卡片有缩略图和剧集上下文；继续观看下方按媒体库展示最新资源分区。

### 人文关怀
首页展示真实媒体内容时只在 UI 中呈现用户自己的 Emby 数据，不把具体私有媒体标题、访问令牌或播放 URL 写入日志和知识库。卡片图片缺失时显示中性占位，不误导用户为假数据。

## 变更内容
1. 扩展首页 Dashboard 数据模型，新增“按媒体库最新资源”分区。
2. 扩展 Emby API/Repository 聚合，按每个媒体库 `ParentId` 拉取最近几条 Movie/Episode。
3. 增强媒体库封面策略，优先展示 Emby 返回的真实库封面，缺失时保留占位，不使用假封面。
4. 增强媒体卡片展示信息，Episode 显示剧名、季名、集号/集名等上下文，继续观看展示真实缩略图。
5. 改造首页布局，在继续观看下方增加多个媒体库最新资源横排。
6. 补充单元测试和知识库说明。

## 范围边界
- **范围内:** 登录后首页 Dashboard 数据聚合、媒体库卡片名称/封面、继续观看卡片缩略图与剧集信息、每个媒体库最新资源横排、相关测试和知识库。
- **范围外:** 媒体库详情页、分页/无限滚动、搜索、筛选排序设置、收藏/播放进度回写、真实音轨字幕切换、弹幕源接入。
- **拆分说明:** 本方案只覆盖“首页可见信息结构增强”一个闭环；二级媒体库浏览和详情页作为后续独立方案。

## 影响范围
- **模块:** data、domain、ui/home、wiki。
- **文件:** `EmbyApi.kt`、`EmbyItemDtos.kt`、`EmbyRepository.kt`、`EmbyStreamUrlBuilder.kt`、`MediaItemSummary.kt`、`HomeDashboardModels.kt`、`HomeScreen.kt`、`CinematicComponents.kt`、相关测试和知识库。
- **API:** 复用 `Users/{userId}/Items`，新增/调整按 `ParentId` 查询最新资源的 Retrofit 方法参数。
- **数据:** 新增 `EmbyLibraryLatestSection` 或等价领域模型；扩展 `MediaItemSummary` 的缩略图、父级/季集信息字段。

## 核心场景

### 需求: 媒体库真实展示
**模块:** ui/home, data
用户登录后首页顶部媒体库区域展示 Emby 真实库信息。

#### 场景: 媒体库名称与封面
认证成功并加载 Dashboard 后：
- 媒体库卡片标题使用 `Users/{userId}/Views` 返回的 `Name`。
- 卡片封面使用该 View 的 `ImageTags.Primary` 构造图片 URL。
- 如果没有封面图，显示统一占位图，不显示虚构封面。
- 卡片仍展示真实视频数量。

### 需求: 继续观看卡片上下文增强
**模块:** ui/home, data
继续观看列表显示真实缩略图和剧集上下文。

#### 场景: Episode 显示剧集信息
继续观看条目为 Episode 时：
- 卡片标题优先显示剧集名或集标题的合理组合。
- 副标题显示季名、季号/集号、年份等可用上下文。
- 缩略图优先使用 Emby 对该条目返回的 Primary/Thumb/Backdrop 等真实图片字段。
- 进度条继续使用 `UserData.PlayedPercentage` 或 ticks 计算。

### 需求: 每个媒体库最新资源
**模块:** ui/home, data
继续观看下方展示各媒体库最新的几条媒体资源。

#### 场景: 按库展示最新内容
Dashboard 加载完成后：
- 对每个可播放媒体库按 `ParentId` 请求最新 Movie/Episode，限制每库条数。
- 首页在继续观看下方按媒体库名称展示横排，比如“电影 · 最新入库”“电视剧 · 最新入库”。
- 每个横排最多展示规划条数，条目为空的库不显示该横排。
- 点击任意媒体卡片仍走现有播放入口，先加载 `PlaybackInfo` 再播放。

## 风险评估
- **风险:** 对每个媒体库额外请求最新资源会增加首页请求数。
- **缓解:** 每库限制少量条目，复用已获取的 Views，串行或小范围并发，避免全量拉取。
- **风险:** Emby 不同版本对图片字段和排序参数支持差异。
- **缓解:** DTO 字段保持可空，图片按 Primary/Thumb/Backdrop 顺序兜底，排序参数失败时保守显示空分区而不是假数据。
- **风险:** 首页分区增多后在 TV 视口内拥挤。
- **缓解:** 使用纵向 LazyColumn + 横向 LazyRow，保留遥控器焦点路径和固定卡片尺寸。
